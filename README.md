# Практикум по нейросетям для малого бизнеса

Современный одностраничный сайт для практикума Натальи Руцкой.

## Быстрый preview без npm

Если `npm install` не работает, можно посмотреть статическую preview-версию:

```bash
python3 -m http.server 3000
```

После запуска откройте в браузере: `http://localhost:3000`.

Файлы preview-версии:

- `index.html` — структура страницы;
- `styles.css` — дизайн, адаптивность и CSS-анимации;
- `script.js` — частицы, плавное появление блоков и сообщение после отправки формы.

## Один файл для открытия двойным кликом

Если нужен самый простой вариант без сервера, скачайте или откройте файл `preview.html`. В нём уже есть HTML, CSS и JavaScript, поэтому отдельные `styles.css` и `script.js` не нужны.

## Next.js-версия

Основная версия проекта сделана на Next.js, Tailwind CSS и Framer Motion.

```bash
npm install
npm run dev
```

После запуска откройте в браузере: `http://localhost:3000`.

## Фото тренера

В текущей разметке фото подключается как `natalya.jpg`:

- для `preview.html` положите `natalya.jpg` рядом с файлом `preview.html`;
- для Next.js-версии положите `natalya.jpg` в папку `public`.
